# Prompt Figma — Garam (Paparas)

Conçois une application mobile de jeu de cartes appelée **Garam (Paparas)**, un jeu de plis multijoueur d'inspiration africaine/gabonaise, avec une direction artistique premium, moderne, immersive et compétitive.

L'objectif est de créer une expérience comparable aux meilleures applications de jeux mobiles contemporaines : interface élégante, animations fluides, hiérarchie visuelle excellente, feedback immédiat et identité forte.

## 1. Identité visuelle

Créer une identité originale pour **Garam — Paparas**.

### Positionnement

Garam doit évoquer :

* compétition ;
* stratégie ;
* prestige ;
* argent et enjeux ;
* convivialité ;
* culture africaine contemporaine ;
* jeu de cartes traditionnel modernisé ;
* élégance nocturne ;
* énergie et tension autour de la table.

Éviter une esthétique générique de casino occidental.

L'identité doit être **africaine sans tomber dans les clichés**.

### Direction artistique

Style :

**Premium African Gaming × Modern Card Table × Cinematic Mobile UI**

Utiliser :

* textures très légères ;
* motifs géométriques africains subtils ;
* surfaces sombres élégantes ;
* détails dorés ;
* profondeur ;
* ombres douces ;
* effets lumineux très maîtrisés ;
* verre/frosted glass pour certains panneaux ;
* cartes réalistes mais modernisées.

L'interface doit donner l'impression d'une **table de jeu haut de gamme**.

# 17. Animation du pli

Lorsqu'un joueur joue :

1. sa carte quitte sa main ;
2. elle se déplace vers le centre ;
3. elle pivote légèrement ;
4. elle se pose sur la table.

Lorsque les quatre joueurs ont joué :

1. pause de quelques centaines de millisecondes ;
2. mise en évidence de la carte gagnante ;
3. effet lumineux ;
4. toutes les cartes retournent vers le gagnant ;
5. nouveau tour.
